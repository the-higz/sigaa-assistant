# SIGAA Assistant

Automação para coleta e organização de atividades acadêmicas do SIGAA.

## Objetivo

O projeto tem como objetivo acessar o SIGAA, identificar atividades acadêmicas pendentes e organizá-las de forma prática para acompanhamento dos prazos.
